## Jerarquía de decisiones

1. Los principios globales son restricciones del proyecto.
2. Las decisiones aprobadas en una etapa concretan esos principios, pero no pueden contradecirlos sin registrar explícitamente el cambio.
3. Las preferencias y ejemplos no son decisiones cerradas.
4. Los documentos de etapas futuras son briefs de entrada; no autorizan implementación anticipada.

## Estados utilizados

- **Principio:** restricción estable definida por el responsable del proyecto.
- **Preferencia:** dirección inicial que debe validarse.
- **Hipótesis:** supuesto que requiere investigación o evidencia.
- **Pendiente:** decisión que corresponde a una etapa posterior.
- **Requisito de entrega:** condición verificable que deberá cumplir la implementación.
