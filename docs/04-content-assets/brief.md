# Brief de Content & Assets

## Estado

**Paquete editorial v1 actualizado con el cuestionario del cliente.** Propuesta, audiencia, servicios, trayectoria, zona y objetivos ya están confirmados como fuente editorial. La publicación permanece bloqueada por datos de contacto, archivos de marca y proyectos/media todavía no entregados.

## Principios editoriales

- No inventar servicios, obras, clientes, métricas, certificaciones o cobertura geográfica.
- Explicar qué hace Aluminica antes de pedir una acción.
- Probar las afirmaciones mediante proyectos, procesos, datos o detalles reales.
- Mantener titulares breves; reservar precisión técnica para cuerpo, captions y fichas.
- Usar una sola llamada a acción primaria consistente.
- Mostrar placeholders durante producción y hacer fallar el build público si permanece alguno requerido.

## Convención de placeholders

`{{NOMBRE_DEL_DATO}}` identifica texto o dato requerido no confirmado. `null` identifica un asset o campo opcional todavía ausente. Ninguno es contenido público.

## Criterio de salida

La etapa queda lista para Development cuando:

- propuesta de valor, servicios y CTA están aprobados;
- datos legales y de contacto están verificados;
- existen al menos tres proyectos publicables o se aprueba una narrativa alternativa;
- logo primario/inverso y media del hero están disponibles;
- cada afirmación importante tiene evidencia;
- derechos y créditos de media están documentados;
- no quedan placeholders `required` en las rutas que se publicarán.
